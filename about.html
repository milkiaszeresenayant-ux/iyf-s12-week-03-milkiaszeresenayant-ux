About this portfolio

This site is a learning project for practicing the tools and workflows used to build and maintain websites. It brings the Week 3 lessons on the command line and Git together in one place.

How I work

I aim to keep projects clear, accessible, and easy to maintain. I use small, focused changes and meaningful version-control history to make progress easy to review.

What I’m learning

  • Navigate and manage files from the command line.
  • Use Git branches and commits to organize changes.
  • Collaborate through GitHub remotes and pull requests.
